## Objective and outcome
**D-014's claim was the milestone's question, and the honest answer is: a business type is
data — but the platform needed three data-shaped generic changes to host a second one**
(installer tuple, KPI mappings field, target direction field). The Finance Tracking type is
pure data (same AST gate as Affiliate), version-gated through three upgrades, and the live
company — Portfolio Watch — ran real cycles that wrote **the first KPI values in the
platform's history**, with attainment reaching the dashboard. Read-only was proven the strong
way: empty declared-action set, both D-013 layers refusing probe proposals, and zero approvals
across every live cycle. The owner's seven compliance rules are on the stored contract and
were asserted verbatim at the outbound prompt boundary.

## The D-026 pilot — measured
Nine M7 lanes (plus OPS-1 before it): **ten worktree lanes, ten merges, zero merge
conflicts, zero main-gate failures after merge.** True wave-0 parallelism (two lanes fully
overlapped, 11 and 24 minutes); a live lane and a code lane ran concurrently without
interference; warm resumption was used twice (fix round to the same worker, verdict pass to
the same reviewer) at a fraction of cold-start cost. Three unplanned lanes were born from
escalations — each got a packet file before code, and the audit's explicit finding is that
the lane workflow *strengthened* discipline rather than diluting it. The 70%-capacity rule
proved right: discovery consumed the reserve exactly as predicted.
