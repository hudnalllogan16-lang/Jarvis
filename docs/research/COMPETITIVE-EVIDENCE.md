## Category observations (2026-07-29 sweep 1)

- **"Agent OS" is now a named category.** Multiple 2026 sources describe "a layer above
  the operating system that mediates between human intent and system capabilities" —
  persistent, memory-equipped personal agents orchestrating tools/APIs
  ([SitePoint](https://www.sitepoint.com/the-rise-of-open-source-personal-ai-agents-a-new-os-paradigm/),
  [ChatbotX](https://chatbotx.io/blog/personal-ai-agent-how-to-design-your-own-intelligent-daily-operating-system-in-2026/)).
  Enterprise variants are defined as infrastructure managing agent lifecycle: scheduling,
  memory, tool orchestration, governance enforcement, observability
  ([Simplai](https://simplai.ai/blogs/best-agentic-ai-operating-systems-2026-enterprise-comparison/)).
- **Long-running background execution is 2026's defining shift** — execution loops running
  for extended periods, background environments purpose-built for them
  ([Symphony](https://symphony-solutions.com/insights/ai-agents-in-2026),
  [Medium/Patten](https://medium.com/@dave-patten/the-state-of-ai-coding-agents-2026-from-pair-programming-to-autonomous-ai-teams-b11f2b39232a)).
- Market framing per comparison press: Manus and Genspark push hardest on raw async
  autonomy; ChatGPT Agent the accessible all-rounder; Devin owns autonomous coding with
  OpenHands as the open twin; Claude trades some autonomy for tighter oversight
  ([web3aiblog](https://www.web3aiblog.com/blog/best-autonomous-ai-agents-2026)).

## Product entries

### Manus (2026-07-29, secondary sources — needs primary verification)
- Autonomous multi-step task execution in its own secure cloud sandbox; positioned for
  deep autonomous execution and professional-grade outputs.
- **Now part of Meta** per site footer noted by comparison press
  ([allaboutai](https://www.allaboutai.com/comparison/genspark-vs-manus-ai/),
  [Flowith blog](https://flowith.io/blog/flowith-vs-manus-vs-genspark/) — competitor
  source, weigh accordingly).

### Genspark (2026-07-29, secondary sources — needs primary verification)
- "Mixture of Agents": blends outputs from ChatGPT, Claude, Gemini with fact-checking.
- "Call for Me" agent places real phone calls to businesses (appointments, inventory) —
  an out-of-band action surface ([allaboutai](https://www.allaboutai.com/comparison/genspark-vs-manus-ai/)).
